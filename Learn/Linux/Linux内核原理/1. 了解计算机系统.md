# 一、了解计算机系统

## 1 计算机硬件

### 1.1 计算机内核框图
![[Pasted image 20260812002925.png]]

> 对于32位计算机系统，一个字就是四字节，对于64位就是8字节。

- **PC (Program Counter)**：程序计数器，大小为一个字的存储空间，存放下一条待执行指令的地址。处理器的运行过程就是不断执行 PC 指向的指令，然后将新的指令地址存入 PC 中。
- **Register**：CPU 内部的单字长存储单元，用于存放指令、地址或运算中间结果。访问速度最快。
- **Main Memory（主存）**：处理器执行程序时，存放程序的指令以及数据。物理上就是一块 DRAM 芯片，逻辑上可以看作一个按字节寻址的大数组。
- **总线**：用来传输数据和指令的通道，通常被设计成一次传输固定长度的字块（如 4 字节或 8 字节）。
- **输入输出设备（I/O）**：键盘、鼠标、显示器、磁盘等，通过控制器和适配器与 I/O 总线相连。

### 1.2 高速缓存（Cache）

| 存储层次 | 典型容量 |
|---|---|
| Register（寄存器） | 100 ~ 1000 B |
| Main Memory（主存） | 1 ~ 100 GB |
| Disk（磁盘） | 1 ~ 1000 TB |

> 对 CPU 而言：访问寄存器的速度 >> 访问主存 >> 访问磁盘。
> 访问寄存器大约比访问内存快两个数量级（~100 倍），因此需要 **Cache（高速缓存）** 来弥合 CPU 与内存之间的速度鸿沟。

现代 CPU 通常分为三层 Cache：

- **L1 Cache**：最靠近 CPU 核心，访问速度接近寄存器，但容量最小（通常 32KB ~ 64KB）。
- **L2 Cache**：访问速度约为 L1 的 1/5，容量更大（通常 256KB ~ 512KB）。
- **L3 Cache**：多核共享，容量最大（数 MB 到数十 MB），访问速度比 L2 慢。

## 2 操作系统

![[Pasted image 20260812003002.png]]

为了防止应用程序对硬件系统的胡乱调用，同时为了简化开发，我们引入了**操作系统**。操作系统对底层硬件进行抽象，向上提供统一、便捷的接口（如文件、进程、虚拟内存等抽象）。

### 2.1 进程与线程

- **进程（Process）**：现代操作系统中，进程是**资源分配**的基本单位。每个进程拥有独立的地址空间、文件描述符表等资源。
- **线程（Thread）**：线程是**CPU 调度**的基本单位。一个进程可以由多个线程组成，同一个进程内的所有线程共享该进程的内存空间和资源。

> 进程运行所需要的所有状态信息（寄存器值、页表、打开的文件等）被称为**上下文（Context）**。操作系统通过上下文切换（Context Switch）在不同进程之间切换 CPU。

### 2.2 虚拟内存

虚拟内存为每一个进程提供一个假象——每个进程都仿佛独自占用整个主存空间。每个进程看到的地址空间都是一样的，这称为**虚拟地址空间（Virtual Address Space）**。

![[Pasted image 20260812003019.png]]

> 虚拟内存的核心机制：CPU 通过 **MMU（Memory Management Unit）** 将虚拟地址转换为物理地址，以**页（Page）** 为基本单位进行映射。

## 3 并行与性能优化

### 3.1 阿姆达尔定律（Amdahl's Law）

阿姆达尔定律描述了通过并行化提升系统性能的理论上限：

$$S = \frac{1}{(1 - \alpha) + \frac{\alpha}{n}}$$

- $S$：总体加速比
- $\alpha$：程序中可被并行化的比例
- $n$：并行处理器的数量

> **关键结论**：即使有无限多个处理器，整体加速比也被程序中**不可并行化的串行部分**所限制。例如，若程序 10% 的部分无法并行化（$\alpha = 0.9$），则理论最大加速比为 $\frac{1}{0.1} = 10$ 倍。

### 3.2 获得更高计算能力的三种途径

1. **线程级并发（Thread-Level Parallelism）**：多个线程或进程同时运行，利用多核 CPU 提升吞吐量。
2. **指令级并行（Instruction-Level Parallelism）**：CPU 在单条指令流水线中同时执行多条指令的不同阶段（流水线、超标量、乱序执行等），由硬件自动完成。
3. **单指令多数据并行（SIMD）**：一条指令同时对多个数据执行相同操作（如 MMX、SSE、AVX 等向量指令集）。

## 4 小结

| 概念 | 一句话总结 |
|---|---|
| 冯·诺依曼架构 | 程序和数据都存在主存中，CPU 逐条取指执行 |
| Cache | 利用局部性原理，弥补 CPU 与内存的速度鸿沟 |
| 操作系统 | 抽象硬件，提供进程、虚拟内存、文件等统一接口 |
| 进程 vs 线程 | 进程是资源容器，线程是执行单元 |
| 虚拟内存 | 让每个进程以为自己独占内存，实际通过 MMU + 页表映射 |
| 阿姆达尔定律 | 并行加速受限于串行部分，盲目堆核不是万能药 |
