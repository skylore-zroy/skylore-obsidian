# 1.启动文件详解

1. 设置堆栈指针SP
2. 设置PC指针（进入复位中断函数）
3. 配置系统时钟
4. 配置外部SRAM用于程序变量等
5. 调用C库中的main函数，最终调用main函数

#### 1 栈
开辟栈空间，用于局部变量，函数调用以及函数的参数
```C
Stack_Size      EQU     0x00000400

                AREA    STACK, NOINIT, READWRITE, ALIGN=3
Stack_Mem       SPACE   Stack_Size
__initial_sp
```
- EQU是表示宏定义的伪指令
- AREA表示开辟一段可读可写的数据空间
  - STACK 表示段的名字
  - NOINIT 表示初始不需要填入初始数据
  - READWRITE 可读可写
  - ALIGN=3 按照2的3次方（8）对齐
- SPACE 表示给上面的段分配内存空间，大小位Stack_size
- __initial_sp 作为标号放在SPACE的后面表示栈顶的地址

#### 2 堆
主要用于动态内存分配（malloc）
```C
Heap_Size       EQU     0x00000200

                AREA    HEAP, NOINIT, READWRITE, ALIGN=3
__heap_base
Heap_Mem        SPACE   Heap_Size
__heap_limit
```

#### 3 指令
```C
                PRESERVE8
                THUMB

; Vector Table Mapped to Address 0 at Reset
                AREA    RESET, DATA, READONLY
                EXPORT  __Vectors
                EXPORT  __Vectors_End
                EXPORT  __Vectors_Size
```
- 表示堆栈内存八字节对齐
- 采用Thumb2指令集
- 开辟一个代码段，只读
- EXPORT 标号申明位外部可用，用于提供给外部引用，主要用于连接器用于连接库文件或其他文件

#### 4 中断向量表
```C
__Vectors       DCD     __initial_sp                ; Top of Stack
                DCD     Reset_Handler              ; Reset Handler
                ......
; External Interrupts
                DCD     WWDG_IRQHandler              ; Window WatchDog
                ......
                DCD     0                            ; Reserved
                DCD     RNG_IRQHandler                ; RNG
                DCD     FPU_IRQHandler                ; FPU
__Vectors_End
__Vectors_Size  EQU     __Vectors_End - __Vectors
```
DCD表示分配一个4字节的空间，存放中断服务函数的函数地址
一旦MCU检测到中断，就需要通过中断向量表赋值给PC，最后跳转到中断向量表的函数的地址。 

#### 5 复位中断函数
```C
 AREA    |.text|, CODE, READONLY

; Reset Handler
Reset_Handler   PROC
                EXPORT  Reset_Handler             [WEAK]
                IMPORT  SystemInit
                IMPORT  __main
                LDR     R0, =SystemInit
                BLX     R0
                LDR     R0, =__main
                BX      R0
                ENDP
```
**作用**：
1. 调用 SystemInit() 函数，完成时钟、Flash 等硬件初始化
2. 跳转到 __main，进入 C/C++ 运行环境（最终到 main()）

**讲解**：
1. LDR：Load Register
    把一个值加载到某个寄存器
2. BLX：Branch with Link and eXchange
    跳转去执行函数，保存返回地址到LR（R14），可切换指令集
3. BX：Branch and eXchange
    跳转到指定地址，不保存指定地址

**_main**
1. 初始化 .data（全局变量初值拷贝到 RAM）
2. 清零 .bss（未初始化全局变量）
3. 初始化 C/C++ 运行环境
4. 最后才调用你写的 main()
