# 2 存储器重映射

CPU上电后固定从 `0x00000000` 取栈顶（SP），从 `0x00000004` 取复位向量（PC）。重映射即根据 BOOT 引脚，将不同物理存储器映射到该地址区域：

| 启动模式 | 映射到 0x00000000 的对象 |
| -------- | ------------------------ |
| Flash 启动 | 主 Flash |
| 系统存储器启动 | 片上 Bootloader |
| SRAM 启动 | 内嵌 SRAM |

- 重映射由硬件根据 BOOT 电平自动完成
- 物理存储器仍可通过原始地址访问（如 Flash `0x08000000`）
- SRAM 启动常用于调试，程序掉电即丢失

### 2.1 主 Flash
- 物理地址 `0x08000000`，**最常用的启动方式**
- 存放用户应用程序，掉电不丢失
- 重映射后 CPU 可直接从 Flash 取指执行，无需额外加载

### 2.2 系统存储器
- 物理地址 `0x1FFF F000`（以 STM32F1 为例，不同系列有别）
- 存放芯片**出厂预置的 Bootloader**，用户不可修改
- 支持 ISP（In-System Programming），可通过 USART1 等串口烧写程序
- 当用户 Flash 被意外擦除或锁死时，可通过此模式恢复

### 2.3 内嵌 SRAM
- 物理地址 `0x20000000`，掉电即丢失
- 常用于**在线调试**或需要频繁更新代码的场景
- 程序需先由调试器或另一启动源加载到 SRAM，再由 CPU 执行
