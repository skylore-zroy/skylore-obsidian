# 六、存储器层次结构

存储器层次结构用少量高速存储器缓存大量低速存储器中的热点数据，在成本、容量和速度之间取得平衡。

---

## 1. 存储层次

| 层次 | 容量 | 速度 | 典型设备 |
|---|---|---|---|
| 寄存器 | 最小 | 最快 | CPU 内部寄存器 |
| L1/L2/L3 Cache | 小到中等 | 很快 | SRAM 缓存 |
| 主存 | 较大 | 中等 | DRAM |
| SSD / HDD | 很大 | 较慢 | 外部存储 |

越靠近 CPU，容量通常越小、速度越快、单位成本越高。

## 2. 局部性原理

缓存有效依赖程序的局部性：

- **时间局部性**：最近访问的数据很快可能再次访问；
- **空间局部性**：访问一个地址后，其附近地址很快可能被访问。

循环变量、顺序数组遍历通常具有良好局部性；随机跳跃访问则较差。

## 3. Cache 的组织

缓存以 **缓存块（cache block）** 或 **缓存行（cache line）** 为单位从下一层取数据。一个地址可划分为：

```text
| 标记（tag） | 组索引（set index） | 块偏移（block offset） |
```

- 块偏移：定位缓存行中的具体字节；
- 组索引：定位可能存放的缓存组；
- 标记：验证这一行是否正是所需的内存块。

## 4. 映射方式与未命中

| 映射方式 | 特点 |
|---|---|
| 直接映射 | 每个内存块只有一个固定位置，简单但冲突多 |
| 组相联 | 每组可存多个块，折中方案 |
| 全相联 | 可放任意位置，灵活但查找成本高 |

缓存未命中常分为：

- **强制未命中**：第一次访问数据；
- **容量未命中**：工作集超过缓存容量；
- **冲突未命中**：多个块映射到同一位置。

## 5. 写策略

- **写直达（write-through）**：写缓存时立即写下一层，简单但写流量大；
- **写回（write-back）**：仅当缓存行被替换时写回，效率高但需要脏位；
- **写分配（write-allocate）**：写未命中时先把块读入缓存再写；
- **非写分配**：写未命中时直接写下一层。

## 6. 小结

> 优化内存性能的第一原则：让程序尽可能连续地重复访问有限的数据集。

| 概念 | 一句话总结 |
|---|---|
| 局部性 | 最近和附近的数据更可能再次被使用 |
| 缓存行 | Cache 与下一层之间搬运数据的基本单位 |
| Cache miss | 所需数据不在缓存中，需要从下一层取回 |
| 写回 | 延迟写入，减少下层写流量 |
