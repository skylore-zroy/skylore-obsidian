# HAL与LL
HAL库拥有更简单的调用，LL库拥有更高的运行效率，两者之间不是完全独立的，存在一定程度上的耦合。

# 1 HAL
## 1.1 配置文件
利用各种宏定义完成了对外设所在文件的调用，也包括一些内核层面的设备的配置。

## 1.2 启动流程
### 1.2.1 HAL库初始化
1. HAL_Init
主要是初始化 SysTick 定时器，此时时钟为内部 HSI

2. SystemClock_Config
 配置时钟树（HSE/HIS、PLL、分频器）。主频依具体型号而定（如 STM32H7 可达 480MHz）

### 1.2.2 外设初始化
- xxxInit 初始化配置参数和开启时钟
- xxxMSPInit 完成具体的引脚和寄存器配置，配置NVIC

# 2 LL
## 2.1 特点
- **面向寄存器**的薄封装，每个函数基本对应单次寄存器操作
- 近乎裸机性能，编译后代码体积远小于 HAL
- 不依赖 HAL 的状态机和句柄，适合对执行时间敏感的场景

## 2.2 与 HAL 的耦合
- LL 可独立使用，但 ST 允许 **HAL 与 LL 混合编程**
- 典型搭配：初始化阶段用 HAL（方便），**关键时序路径**用 LL（高效）
- 同一外设不建议同时用 HAL 和 LL 混控，避免状态机冲突
